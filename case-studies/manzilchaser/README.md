# ManzilChaser case study

This page implements Figma frame `176:4894`.

- Edit `page.html` for the case-study text and section order.
- Edit `styles.css` for layout, typography and responsive styles.
- `exploration.html` and `exploration.css` contain the seven small design exploration screens.
- `assets/` contains original Figma images, sketches, icons and grid texture.
- `brand.png`, `title.png` and `thank-you.png` preserve the custom lettering exported from Figma; replace these exports if their lettering changes.

Run `npm run build` from the project root to assemble this page into `index.html` and include it in `dist/`.
