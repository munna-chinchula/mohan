# Hero

Shared content: `index.html`. Device styling: `laptop/styles.css`, `tablet/styles.css`, and `mobile/styles.css`. Common rules remain in `styles.css`.

The hero uses `assets/botanical-vortex.mp4` with muted autoplay, looping, and inline playback. Its fallback poster is `assets/bouquet-hero.png`. Navigation content is in `navigation.html`; menu behavior is in `navigation.js`. Shared website navbar styling is in `styles/navigation.css` at the project root.

See root `EDITING.md` for the complete editing guide.
