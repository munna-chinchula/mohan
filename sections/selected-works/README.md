# Selected Works

Edit `index.html` and `styles.css` for the section heading and shared card layout. Edit `projects.json` to change project order.

Each project has its own folder:

- `manzilchaser/`: homepage card and full case study.
- `vasthra-shree/`: homepage card; case study pending.
- `academic-app/`: homepage card; case study pending.
- `parkease/`: homepage card; case study pending.

For a homepage card, edit that project's `card.html`, `card.css`, and `assets/`. For the ManzilChaser case study, open its `sections/` folder and select the chapter to edit. Read its `EDITING.md` for details.

Refresh the local preview after edits. Run `npm run build` before publishing.
